# Find and evaluate a named argument of the f(\<comp\>, ...) term in a formula. Used to recover, e.g., \`season.length\` or \`Cmatrix\` from the fitted call.

Find and evaluate a named argument of the f(\<comp\>, ...) term in a
formula. Used to recover, e.g., \`season.length\` or \`Cmatrix\` from
the fitted call.

## Usage

``` r
ngvb_find_f_arg(fit, comp.name, argname)
```
