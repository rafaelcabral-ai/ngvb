# Summary of an ngvb fit: the underlying INLA summaries plus, per component, the non-Gaussianity parameter and the most strongly down-weighted (outlying) indices.

Summary of an ngvb fit: the underlying INLA summaries plus, per
component, the non-Gaussianity parameter and the most strongly
down-weighted (outlying) indices.

## Usage

``` r
# S3 method for class 'ngvb'
summary(object, n.flag = 5, ...)
```

## Arguments

- object:

  An \`ngvb\` object.

- n.flag:

  Number of top mixing-variable indices to report per component.

- ...:

  Ignored.

## Value

The \`ngvb\` object, invisibly; called for the summary it prints.
